봉사활동 확인서 ↔ 나이스 대조 프로그램

모든 처리는 이 브라우저 안에서만 이루어집니다(개인정보 외부 전송 없음). 한글(HWP)에서 바로 변환한 PDF·엑셀 파일은 글자를 그대로 정확하게 읽고, 스캔본은 글자 인식(OCR) — 사진 속 글자를 컴퓨터가 읽어내는 기술 — 으로 처리합니다(스캔본이 있을 때만 첫 실행 시 인터넷 필요).

📖 사용법 · 유의사항 (처음 사용 전 꼭 읽어 주세요)

무엇을 하는 프로그램인가요?

봉사활동 확인서(PDF·엑셀)와 나이스 입력 결과(엑셀)를 자동으로 비교해서, 빠졌거나 잘못 입력된 부분만 찾아 줍니다. 연간 계획서를 넣으면 계획대로 다 입력됐는지도 함께 점검합니다.

사용 순서

  1. 파일 선택 — ① 나이스 엑셀: 나이스 → 학생부 → 항목별 조회 → 봉사활동상황(현재학년) 다운로드 파일 그대로(편집 금지) ② 확인서: 스캔한 PDF, 한글에서 PDF로 저장한 파일, 엑셀 파일 모두 가능(여러 개 가능) ③ (선택) 연간 계획서 PDF 첨부 또는 계획 직접 입력
  2. [파일 읽기 시작] 클릭 — 자동으로 내용을 읽습니다. 스캔본은 글자 인식 때문에 페이지당 몇 초, 첫 실행은 1~2분 걸립니다.
  3. 2단계 확인 — 페이지마다 원본(이미지 또는 표 내용)과 읽어낸 내용(날짜·활동·시간·참가자)이 맞는지 비교하고 다르면 고칩니다. 가장 중요! 비고란에 불참·결석·지각·조퇴가 있는 학생은 체크가 풀려 있어야 합니다. 자동으로 풀리지만(빨간 사유 표시), 스캔 상태에 따라 놓칠 수 있으니 비고란과 체크 상태를 반드시 눈으로 대조하고, 안 풀렸으면 직접 해제하세요. 체크 해제 = 나이스에 없어야 정상이라는 뜻입니다.
  4. [대조 실행] — 결과에서 빨간색 항목만 확인하면 됩니다. [결과 복사] 버튼으로 엑셀에 붙여넣을 수 있습니다.

결과 판정의 의미

  • 나이스 누락(미입력): 확인서엔 있는데 나이스에 없음 → 입력 필요
  • 확인서 비고 '조퇴' — 입력됨(삭제 필요): 불참·조퇴 학생이 입력되어 있음 → 삭제 필요
  • 시간·날짜·내용 불일치 / 누계 오류: 입력값이 확인서와 다름 → 수정 필요
  • 계획 점검의 '완료 · 비고/불참 제외 N명': 정상입니다(제외자는 미입력이 맞음)

유의사항

  • 모든 파일은 이 컴퓨터 안에서만 처리됩니다. 학생 정보가 외부로 전송되지 않습니다.
  • 스캔본은 글자 인식이 완벽하지 않습니다. 2단계 확인 없이 결과를 그대로 믿지 마세요. 도장 찍기 전 한글 원본을 PDF로 저장한 파일이나 엑셀 확인서를 쓰면 훨씬 정확하고 빠릅니다.
  • 계획서 자동 추출은 표의 학년별 열 위치까지는 구분하지 못합니다. 우리 학년에 해당 없는 날짜가 섞이면 입력란에서 그 줄을 지우세요. (엑셀을 먼저 선택하면 학년에 맞게 추출)
  • 학기 중간에 점검할 때는 계획 입력란에서 아직 안 지난 날짜 줄을 지우고 실행하세요.
  • 최종 판단은 반드시 원본 확인서와 나이스 화면에서 직접 확인 후 처리하세요. 이 프로그램은 점검 보조 도구입니다.

1단계. 파일 선택

나이스 엑셀 파일(.xlsx)
나이스 → 학생부 → 항목별 조회 → 봉사활동상황(현재학년)에서 다운로드한 엑셀 파일 그대로 사용 (편집 불필요)
봉사활동 확인서 파일 (PDF·엑셀, 여러 개 가능)
교내봉사활동확인서(학급/소집단) — 스캔한 PDF, 한글(HWP)에서 PDF로 저장한 파일, 엑셀 파일 모두 가능. 스캔본은 자동으로 글자 인식(OCR) 처리되고, 한글 변환본·엑셀은 글자 그대로 정확하게 읽힙니다
연간 봉사활동 계획서 PDF (선택) — 첨부하면 계획 날짜를 자동 추출합니다
⚠ 유의사항 — 봉사활동이 자율·자치활동 표 안에 섞여 있는 계획서는 표의 학년별 열 위치까지는 읽지 못합니다. 학년마다 시행 날짜가 다른 활동이 있으면 다른 학년의 날짜가 함께 추출될 수 있으니, 추출 후 위 입력란에서 우리 학년에 해당하지 않는 날짜 줄을 지운 뒤 대조를 실행하세요. (나이스 엑셀을 먼저 선택하면 학년에 맞춰 추출합니다)

2단계. 읽어낸 내용 확인·수정 — 원본 이미지를 보며 날짜·내용·시간·참가자를 확인하세요. 스캔본은 이름이 잘못 읽히기 쉬워 학급 명단 체크박스로 표시합니다.
